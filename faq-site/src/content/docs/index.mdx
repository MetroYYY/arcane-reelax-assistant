## 快速开始

- 不清楚某个设置有什么用：从左侧选择对应的功能分类。
- 知道问题关键词：使用页面顶部的搜索功能。
- 想逐项确认自动化是否正常：开启对应功能后点击面板底部的“立即检查”按钮，再到“日志”查看识别场景、跳过原因和执行结果。
- 第一次使用属性加点：阅读[属性加点功能介绍](/faq/资产/属性加点/)。
- 想了解最近的变化：查看[更新历史](/faq/关于/更新历史/)。
- 想查看玩家问卷结论：阅读[问卷调查结果](/faq/关于/问卷调查结果/)。
- 愿意支持脚本维护：前往[支持开发、功德碑与资金流向](/faq/关于/支持开发/)。
- 需要安装、更新或回退脚本：查看[下载链接](/faq/关于/下载链接/)。

## 文档分类

- **日常**：地图导航、鱼饵切换、船队管理、公会管理。
- **赛事**：比赛辅助、世界 Boss、奥秘献祭。
- **资产**：Buff 购买、属性加点、地图专精献祭、出售鱼类、出售装备。
- **其他**：通用辅助、显示与统计。
- **顶部分页**：设置、日志、反馈、关于；本站导航采用相同顺序，“关于”固定在最后。

:::note[阅读说明]
完整功能文档通常按照“功能用途 → 使用条件 → 设置说明 → 使用示例 → 常见问题”的顺序编写。脚本面板中的问号只提供简短提示，详细说明以本站文档为准。
:::

:::caution[立即检查也会执行操作]
“立即检查”会按当前开关和设置运行一次真实检查，不是只读预览。Buff 购买、献祭、洗点、船队上缴与续费、出售鱼类和出售装备等功能在条件满足时可能立即消耗资源或提交操作，请先核对配置。
:::
