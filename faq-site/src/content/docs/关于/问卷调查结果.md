这里公开辅助脚本两次问卷的统计结果。统计截至 **2026 年 8 月 24 日**。

## 统计方法

- 以游戏公开玩家 ID 去重，同一玩家重复提交时保留最后一次回答。
- 排除了 5 条缺少问卷编号、无法准确归类的历史记录。
- 多选题按该题实际作答人数计算，因此各选项比例相加可能超过 100%。
- 问卷由愿意填写的脚本用户自愿参与，结果用于辅助判断，不代表全部玩家。

## 消息推送问卷

有效样本为 **76 人**。

| 是否需要消息推送 | 人数 | 比例 |
| --- | ---: | ---: |
| 不需要 | 38 | 50.0% |
| 需要 | 27 | 35.5% |
| 无所谓 | 11 | 14.5% |

其中 38 人继续回答了推送方式和内容偏好。

### 推送渠道

| 渠道 | 人数 | 比例 |
| --- | ---: | ---: |
| 个人微信 | 25 | 65.8% |
| 个人 QQ | 24 | 63.2% |
| 企业微信 | 4 | 10.5% |
| 独立 App / Bark | 2 | 5.3% |
| 钉钉 | 1 | 2.6% |
| 飞书 | 1 | 2.6% |

另有 22 人（57.9%）表示只想使用微信或 QQ，16 人（42.1%）可以接受独立 App。

### 推送内容

| 内容 | 人数 | 比例 |
| --- | ---: | ---: |
| 奇异或奥秘鱼／装备 | 32 | 84.2% |
| 保底进度 | 28 | 73.7% |
| 比赛开赛预告／结果 | 25 | 65.8% |
| 每小时鱼获汇总 | 25 | 65.8% |
| 船队航线变动 | 14 | 36.8% |
| 奥术涌动天气 | 13 | 34.2% |
| 金风天气 | 12 | 31.6% |
| 公会增益变化 | 10 | 26.3% |

在频率偏好中，27 人（71.1%）选择只推送重要事件，23 人（60.5%）可以接受每小时汇总，10 人（26.3%）希望尽量详细。

### 当前决定

推送需求比较分化，暂不优先开发独立 App。若后续实现，会优先考虑微信、QQ，以及珍稀钓获、保底和比赛等高价值提醒，并默认减少打扰。

## 自愿赞助问卷

有效样本为 **59 人**。

| 对自愿赞助入口的态度 | 人数 | 比例 |
| --- | ---: | ---: |
| 接受 | 34 | 57.6% |
| 无所谓 | 20 | 33.9% |
| 不接受 | 5 | 8.5% |

接受或无所谓合计 **91.5%**。除 5 位选择“不接受”的玩家外，共有 54 人继续回答赞助方式和公开账目偏好。

### 可接受的赞助方式

| 方式 | 人数 | 比例 |
| --- | ---: | ---: |
| 微信赞赏码 | 29 | 53.7% |
| 支付宝收款码 | 29 | 53.7% |
| 爱发电等赞助平台 | 23 | 42.6% |
| 只接受入口，暂不考虑赞助 | 14 | 25.9% |

### 是否公开赞助收支

| 偏好 | 人数 | 比例 |
| --- | ---: | ---: |
| 无所谓 | 25 | 46.3% |
| 希望定期公开 | 20 | 37.0% |
| 不必公开 | 9 | 16.7% |

### 当前决定

赞助功能已经开放，并坚持完全自愿，不影响任何脚本功能。玩家可以在[支持开发](/faq/关于/支持开发/)页面选择爱发电、微信或支付宝；功德碑和资金流向也会在该页面不定期公开。
