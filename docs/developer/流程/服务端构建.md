# 服务端构建要求

只要修改 `server` 下的 Go 服务端代码，发布前都必须完成测试，并生成适用于 Debian 12 amd64 的静态可执行文件。

在项目根目录使用 PowerShell：

```powershell
Set-Location server
go test ./...
$env:GOOS = "linux"
$env:GOARCH = "amd64"
$env:CGO_ENABLED = "0"
go build -trimpath -o collector-linux-amd64 .
```

发布产物为 `server/collector-linux-amd64`。`CGO_ENABLED=0` 用于避免目标服务器缺少本机动态库导致无法启动。
