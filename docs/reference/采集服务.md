# 采集服务

本文记录仓库 `server/` 目录当前实现、脚本上报链路、运行文件和部署检查方法。内容以当前源码为准。

## 1. 当前线上状态

2026-08-23 从外网只读检查以下地址：

- `https://reelax.hsiyue.com/`
- `https://reelax.hsiyue.com/version`

两者均由 OpenResty 返回 `502 Bad Gateway`。因此目前最新版脚本还不能把使用统计写入线上服务。域名、TLS 和 OpenResty 已经可达，故障点位于 OpenResty 到 `127.0.0.1:8000` 的上游连接，常见原因是 Go 进程未运行、进程启动目录或权限错误、监听失败，或者启动后立即退出。

恢复后，根路径应返回：

```json
{"ok":true,"service":"reelax-collector"}
```

`/version` 应返回类似：

```json
{"version":"2.0.0"}
```

## 2. 脚本如何上报

脚本使用 `https://reelax.hsiyue.com` 作为采集服务地址。游戏 API 就绪、取得玩家 UID 后会调用 `POST /usage`，发送 `uid`、玩家名和脚本版本。

- 最多等待玩家 UID 30 秒。
- 同一脚本版本在浏览器本地记录 24 小时冷却。
- 只有服务端返回 `ok: true` 或 `dup: true` 后才写入冷却时间；网络错误或 502 不会被当成成功。
- 问卷、Bug 报告和建议分别使用 `/survey`、`/report`、`/feedback`。
- FAQ 页面访问由文档站使用 `/doc-view`，不是用户脚本的使用统计。

服务端若设置了 `COLLECTOR_TOKEN`，除 `/version` 和 `/download` 外都必须携带 `X-Auth-Token`。当前公开脚本不会发送该请求头，因此面向现有脚本部署时必须不设置这个环境变量；否则 `/usage` 等接口会返回 401。

## 3. 源码与配置文件

| 文件 | 用途 |
|---|---|
| `server/main.go` | 采集服务主程序。监听 `127.0.0.1:8000`，提供统计、问卷、文档访问、反馈、工单、管理后台、版本和脚本下载接口。 |
| `server/database.go` | SQLite 初始化、表结构、采集数据写入和旧 CSV 一次性导入。 |
| `server/tickets.go` | 玩家创建、查询和补充工单的 JSON API。 |
| `server/admin.go` | 管理员登录、工单回复/关闭、附件下载和采集数据浏览页面。 |
| `server/go.mod` | Go 模块声明。当前服务只使用标准库，没有第三方 Go 依赖。 |
| `server/nginx.conf` | OpenResty/Nginx 示例配置。将 `reelax.hsiyue.com` 反向代理到 `127.0.0.1:8000`，把脚本下载映射到 `/download`，并直接托管 `/faq/` 静态站点。 |
| `server/latest_version.txt` | `/version` 返回的最新版号，也是统计报告判断旧版玩家的基准。发布时应与脚本版本同步。 |
| `server/cmd/stats-report/main.go` | 离线统计命令。读取 `usage.csv`、`doc_views.csv` 和最新版号，输出近期仍活跃的旧版本玩家、FAQ 页面访问次数及最近可关联访问。 |

## 4. 构建产物与运行数据

| 文件或目录 | 用途 | 是否由源码生成 |
|---|---|---|
| `server/collector` | Linux 版 Go 可执行文件，通常部署到服务器运行。 | 是 |
| `server/reelax-collector.exe` | Windows 版 Go 可执行文件，供本地或 Windows 环境运行。 | 是 |
| `server/usage.csv` | 每次成功使用上报：`uid,name,version,ts`。 | 运行时追加 |
| `server/survey.csv` | 问卷结果；按 `uid + surveyId` 去重。 | 运行时追加 |
| `server/reports.csv` | Bug 报告正文、设置快照、日志文件名和时间。 | 运行时追加 |
| `server/suggestions.csv` | 用户建议。 | 运行时追加 |
| `server/doc_views.csv` | FAQ 访问记录；仓库当前没有该文件时，会在首次成功上报后创建。 | 运行时追加 |
| `server/downloads.csv` | 脚本下载 IP、版本、User-Agent 和时间；仓库当前没有该文件时，会在首次下载后创建。 | 运行时追加 |
| `data/asmy.db` | SQLite 主数据库，保存采集记录、工单、消息、附件索引和 CSV 导入记录。 | 运行时创建 |
| `data/attachments/` | Bug 报告和 Bug 工单附带的日志正文。 | 运行时创建 |
| `server/arcane-assistant.user.js` | `/download` 在无 `version` 参数时读取的最新版脚本。部署时从 `dist/奥术摸鱼大师辅助.user.js` 复制并改为此文件名。 | 发布时复制 |
| `server/releases/arcane-assistant-vX.Y.Z.user.js` | `/download?version=X.Y.Z` 读取的历史脚本。文件内容与对应正式发行脚本保持一致。 | 发布历史版本时上传 |

SQLite 数据库与 `data/attachments/` 含玩家标识、反馈、设置及运行日志，不应提交到公开仓库，也不应由静态 Web 目录直接暴露。旧 CSV 仅用于首次迁移，导入后应移入 `data/archive/`。

## 5. HTTP 接口

| 方法与路径 | 调用方 | 结果 |
|---|---|---|
| `GET /` | 运维健康检查 | 返回服务名和 `ok: true`。 |
| `GET /version` | 用户脚本 | 返回 `latest_version.txt` 中的版本。 |
| `GET/HEAD /download` | Nginx 的脚本下载映射 | 无参数时返回最新版；传入 `version=X.Y.Z` 时返回 `releases/arcane-assistant-vX.Y.Z.user.js`。 |
| `POST /usage` | 用户脚本 | 向 `usage.csv` 追加使用记录。 |
| `POST /survey` | 用户脚本 | 向 `survey.csv` 写入问卷；重复提交返回 `dup: true`。 |
| `POST /report` | 用户脚本 | 写入 Bug 报告及附件日志；同一 UID 冷却 10 分钟。 |
| `POST /feedback` | 用户脚本 | 写入建议；同一 UID 冷却 10 分钟。 |
| `POST /doc-view` | FAQ 文档站 | 写入 FAQ 页面访问记录。 |
| `POST /tickets` | 用户脚本 | 创建工单。 |
| `GET /tickets?uid=...` | 用户脚本 | 按玩家 ID 查询历史工单。 |
| `GET /tickets/{id}?uid=...` | 用户脚本 | 读取指定工单和消息。 |
| `POST /tickets/{id}/messages` | 用户脚本 | 向未关闭工单补充消息。 |
| `/admin/` | 管理员浏览器 | 使用 `ADMIN_TOKEN` 登录，浏览数据、回复和关闭工单。 |

所有公开写接口共享每 IP 每分钟 30 次的内存限流。进程重启会清空限流和反馈冷却，持久数据与问卷去重键保存在 SQLite。首次启动会导入已有 CSV，且不会改写或删除原文件。

## 6. 构建、启动与排查

在 `server/` 目录构建 Linux 服务：

```bash
GOOS=linux GOARCH=amd64 go build -o collector .
```

服务使用相对路径读取版本和下载脚本，所以应把工作目录设为部署目录再启动。SQLite 数据目录由 `ASMY_DATA_DIR` 指定，生产环境建议设为 `/opt/asmy/data`。完整迁移步骤见《SQLite 与工单后台部署》。

服务器上依次检查：

```bash
ss -lntp | grep 8000
curl -i http://127.0.0.1:8000/
curl -i http://127.0.0.1:8000/version
tail -n 100 /opt/openresty/nginx/logs/reelax_error.log
```

若本机 `curl` 正常而公网仍为 502，重新检查 OpenResty 实际加载的配置并 reload；若本机也连接失败，查看采集服务进程日志和退出原因。恢复后再从外网检查根路径与 `/version`。若要验证写入，建议使用专门的测试 UID 调用 `/usage`，随后确认部署目录的 `usage.csv` 新增一行，避免把健康检查混入真实玩家统计。

运行离线统计报告：

```bash
go run ./cmd/stats-report . 7
```

最后一个参数是统计最近多少天，默认为 7。
